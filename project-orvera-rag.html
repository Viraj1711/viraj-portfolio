RAG Knowledge Retrieval Pipeline

At Orvera.ai, I worked on retrieval-augmented generation to connect conversational AI and Agent Assist with relevant knowledge, helping responses reflect the context of a live interaction.

The system & my involvement

My RAG work connects semantic knowledge lookup with model response generation. The system retrieves relevant information through vector search and brings that information into the response context, so the assistant can work with knowledge related to the current conversation. This retrieval layer supports the broader voice and call-center assistance workflows described in my resume.

My contributions

  • Worked on the RAG pipeline as part of the end-to-end conversational and agent-assist systems.
  • Connected embeddings and vector-search knowledge lookup with context-aware model responses.
  • Used LangChain and the vector knowledge base within the retrieval workflow; MongoDB Atlas vector search is part of the resume-listed toolkit.
  • Integrated retrieval with the dual-model Agent Assist architecture, where a higher-capacity model handles deeper knowledge lookup.
  • Coordinated retrieved knowledge with conversation context and Redis-backed session memory.
  • Contributed to improving retrieval usefulness and response latency for real-time support workflows.

Engineering approach

Knowledge in the response path

Retrieval provides information relevant to the interaction before a response is produced. The focus is on bringing the right context into the model workflow, rather than presenting a standalone search result.

Retrieval and memory work together

The current interaction, previous conversation context, and retrieved knowledge play different roles. Redis-backed session state helps maintain conversational continuity while the vector knowledge base supplies relevant reference information.

Accuracy alongside responsiveness

Retrieval is part of a real-time system. My work addressed both useful knowledge lookup and the time needed to return an answer within a voice or support-agent interaction.

Reported outcomes

My resume reports 85%+ RAG retrieval accuracy across real-time call-center support workflows. This is a role-level reported outcome; the website does not reproduce its evaluation dataset.
