ORVERA.AI / LIVE SUPPORT / DUAL MODEL / KNOWLEDGE

End-to-End Agent Assist Copilot

I worked end to end on Agent Assist at Orvera.ai, connecting live conversation processing, fast intent suggestions, deeper knowledge retrieval, session memory, and response streaming for support workflows.

The system & my involvement

Agent Assist supports the human agent during an active conversation. Its dual-model architecture separates fast, immediate intent suggestions from deeper retrieval over a vector knowledge base. The connected backend combines live speech-processing inputs, RAG, persistent context, and streamed output so assistance can follow the ongoing interaction.

My contributions

  • Worked across the Agent Assist backend from real-time communication and conversation processing through retrieval and response delivery.
  • Engineered a dual-model architecture with a fast LLM for intent suggestions and a higher-capacity LLM for deep knowledge retrieval.
  • Integrated RAG and vector knowledge lookup into the support-assistance workflow.
  • Implemented session memory, cross-memory tracking, and context-window management using Redis Cache and Pub/Sub.
  • Supported concurrent call-streaming sessions through FastAPI, AsyncIO, and WebSockets.
  • Delivered chunked model responses to support timely assistance during live interactions.
  • Developed Playwright and BotCity workflow-testing scripts to streamline repetitive verification steps.

Engineering approach

Different models for different jobs

The fast model serves immediate intent suggestions, while the higher-capacity model handles deeper retrieval. The design allocates work according to the responsiveness and knowledge needs of the interaction.

Support the ongoing conversation

Agent Assist combines current conversation information with persistent session state. This connects retrieval and suggestions to the interaction the support agent is handling.

Connect the full backend path

My end-to-end involvement spans live communication, model orchestration, retrieval, Redis memory, and streaming output. These components form a connected support workflow rather than separate demonstrations.

Verify repeatable workflows

Playwright and BotCity scripts automate repetitive verification tasks. They support checking the connected system as changes are made, alongside performance and retrieval improvements.

Reported outcomes

The resume reports 85%+ retrieval accuracy and sub-800 ms voice interaction latency across the related Orvera.ai call-center workflows. These figures describe the overall professional work and are not presented as separate Agent Assist benchmark results.
